## What's new in v1.0.0

First public release of this customized personal homepage (based on [leleo-home-page](https://github.com/leleo886/leleo-home-page)).

### Highlights

- Glassmorphism homepage dashboard (profile, skills, quote, mail)
- **My World** dial: life / sport / game / project + lightbox gallery
- Study blog space + guestbook reviews
- Mini music player with playlist & simple lyrics support
- Interactive mascots:
  - 「我不是神」climber: click-to-move, anger / boom / revive, dance when music plays
  - Muscle buddy: flex poses + hype when music plays
- Config-driven setup via `src/config.js`
- Live demo on Netlify

### Links

- Demo: https://strong-kangaroo-fb7c41.netlify.app/
- Repo: https://github.com/lyw313/leleo-home-page
