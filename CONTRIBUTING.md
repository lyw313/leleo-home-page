# Contributing

Thanks for your interest in improving this personal homepage template!

## Ways to help

- Fix typos / improve README (CN or EN)
- Improve mobile layout and accessibility
- Report bugs with screenshots + browser version
- Suggest wallpaper / UX polish (keep the existing visual language)

## Dev setup

```bash
npm install
npm run dev
```

Please open a Pull Request against `main` with a short description of **why** the change helps.

## Notes

- Site content is mostly configured in `src/config.js`
- Do **not** commit real passwords, EmailJS secrets, or private media you are not allowed to share
